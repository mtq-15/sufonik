# Sufonik

AI customer support assistant for e-commerce stores. Answers the repetitive questions that eat a support team's day — order status, shipping, returns, stock — from the store's real catalog and knowledge base, and escalates to a human when unsure.

This repository hosts the public marketing site (GitHub Pages). The application source lives in a private repository.

## Pages
- `index.html` — landing page with live ROI calculator
- `demo.html` — fully client-side interactive demo (no backend required)
- `pricing.html` — Starter / Pro / Scale plans
- `signup.html` — early-access onboarding

## Positioning
- Works on **any store** — including custom/headless stacks where Gorgias and Storebird can't go
- Flat monthly pricing (no per-reply surprises)
- RAG over the store's own data; never trains on customer data
- Human escalation with full context
